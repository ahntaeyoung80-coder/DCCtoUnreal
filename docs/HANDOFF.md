# 인수인계

## 현재 단계

설계·학습 단계입니다. 사용자가 설계와 범위를 확정하고 구현을 요청하기 전에는 도구 코드를 수정하지 않습니다.

## 합의된 방향

- Unreal Content 계층구조, 네이밍 규칙, 마스터 머티리얼을 먼저 학습하고 확정합니다.
- 이를 바탕으로 초보자용 Unreal 마스터 프로젝트/템플릿을 만들고 배포 형식을 결정합니다. 사용자가 `.upack`을 언급했으며, 실제 형식은 배포 전 확인해야 합니다.
- 생성기는 기존 Unreal 프로젝트 안에서 실행합니다. Blender 익스포터와 Unreal 임포터는 별도 도구로 유지하되 최종 규칙을 공유합니다.

## 다음 단계

초보자용 Unreal Content 계층구조를 설명하고 초안을 제안합니다. `/Game/DCC/Shared`와 `/Game/DCC/Imports/<BundleName>` 구조는 제안만 되었으며 미승인입니다.
