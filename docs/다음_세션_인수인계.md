# 다음 세션 인수인계

## 목표

Blender에서 출력한 FBX/JSON과 Substance Painter 텍스처를 Unreal에 가져오는 워크플로를 개발 중이다. 현재 사용자는 Unreal 경험이 거의 없는 초보자도 최소한의 조작으로 쓸 수 있도록, 마스터 머티리얼과 프로젝트 구조를 별도 베이스 패키지로 제공하고 임포터는 가볍게 유지하려 한다.

## 확정된 요구

- Blender가 `_SM`과 `_SK`를 각각 FBX/JSON으로 출력한다.
- Unreal 임포터가 FBX/JSON을 읽고 같은 이름의 Substance Painter 텍스처를 찾아 머티리얼 인스턴스와 메시 슬롯을 연결한다.
- ORM은 자동 처리한다. 현재 가정한 채널은 R=AO, G=Roughness, B=Metallic이다.
- SSS, Opacity, Emissive 맵은 찾아서 알리고 텍스처로 가져오되, 자동 셰이더 설정은 하지 않는다.
- Base Color 텍스처와 단색(Vector) 경로는 엄격히 분리해야 한다. Multiply는 색상 경로를 오염할 수 있어 최종 방식으로 확정하지 말 것.
- Lerp보다 더 안전하고 초보자에게 노출할 설정을 줄이는 경로 선택을 검토한다. Static Switch는 후보지만 셰이더 permutation 비용도 고려한다.
- 노드 그래프는 겹치지 않게 정리하고, 관련 노드끼리 이름이 있는 그룹으로 묶는다.
- 사용자는 특수 표현을 별도 머티리얼/레이어 구조로 발전시키는 베이스 패키지 구상을 했다. Emissive의 영역별 적용과 SSS/Opacity의 별도 부모 머티리얼 구성을 검토한다.
- 작업 순서: 지금은 **마스터 머티리얼 생성 코드를 임포터에서 분리하는 데까지만** 한다. 베이스 패키지 전체 구현이나 머티리얼 설계 변경은 다음 결정 후 진행.

## 현재 파일

- `unreal/unreal_dcc_importer.py`: FBX/JSON 및 텍스처 임포터. 이제 마스터 머티리얼을 만들지 않고 존재 여부를 검사한다.
- `unreal/unreal_dcc_material_builder.py`: Unreal Editor에서 별도 실행해 `/Game/DCC/Shared/Materials/M_DCC_Master_v2`를 생성한다.
- `unreal/README_unreal_dcc_importer.md`: 실행 순서와 동작 설명(영문/한국어).
- `blender/dcc_batch_exporter.py`: Blender 애드온 소스.
- `blender/README_dcc_batch_exporter.md`: Blender 애드온 설치와 사용 안내.
- `README.md`: 프로젝트 폴더 안내 및 빠른 시작.

## 현재 코드 상태와 주의점

- 생성기/임포터 분리만 완료한 중간 단계다. 최종 베이스 패키지나 Unreal 플러그인은 아직 만들지 않았다.
- 머티리얼 생성기는 기존 프로토타입 그래프를 그대로 옮겼다. 따라서 Base Color는 아직 Multiply 방식이고, ORM/개별 Roughness·Metallic 선택은 아직 Lerp 방식이다. 사용자는 두 경로의 엄격한 분리 및 Lerp 대안을 검토 중이므로 최종 구현으로 간주하지 말 것.
- SSS/Opacity/Emissive를 영역별로 다루는 데 Unreal의 Overlay Material이 적합한지 확정되지 않았다. Material Layers/Material Layer Blend의 마스크 기능과 별도 부모 머티리얼 방식 비교가 필요하다. 특히 Opacity와 SSS는 부모 머티리얼의 Blend Mode/ Shading Model에 영향을 받는다.
- Unreal 프로젝트에서 이전에 임포터 실행은 성공했으나, 이번 코드 변경 이후 생성기와 임포터 순서를 실제 프로젝트에서 재검증하지 않았다.
- 기존 `M_DCC_Master_v2`가 있으면 생성기는 그대로 유지하고 덮어쓰지 않는다.

## 다음 실행 절차

Unreal Editor에서 먼저 `unreal_dcc_material_builder.py`를 실행하고, 성공하면 `unreal_dcc_importer.py`를 실행한다. 임포터 코드가 예상 마스터 에셋을 찾지 못하면 메시/텍스처 작업 전에 중단해야 한다.
